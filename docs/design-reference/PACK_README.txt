GIT QUEST: THE REPOSITORY KINGDOM — VISUAL REFERENCE ASSET PACK

Contents
- Git_Quest_Asset_Board.png: complete concept-art reference board.
- references/: cropped sections of the board for easier use as individual visual references.
- CLAUDE_VISUAL_REDESIGN_PROMPT.txt: prompt for Claude to audit the current game, make a design plan, and implement a visual/UX redesign.

IMPORTANT
These are concept-art references, not a production-ready set of transparent sprites, rigged 3D models, or individually exported UI components. Some crops contain multiple objects and may include small generated text artifacts. Use them to guide the art direction and component design rather than displaying the whole board as a game screen.

Recommended workflow
1. Give Claude access to the actual game repository.
2. Add Git_Quest_Asset_Board.png and the references folder to the project or make them accessible to Claude.
3. Paste CLAUDE_VISUAL_REDESIGN_PROMPT.txt into Claude.
4. Ask Claude to inspect and run the existing game before changing it, then follow the required audit → design plan → implementation → verification workflow.

The Start.ng authentication, centralized styling, and deployment integration must be verified against real platform documentation; this pack does not define those APIs.
